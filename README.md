# Amazon-Sales-Data-Analysis
Amazon Sales Data Analysis using Excel, dashboards, insights, and business recommendations.

## Project Overview
This project analyses Amazon sales data using Microsoft Excel to understand sales performance, product trends, and business opportunities.

## Objectives
- Analyse sales performance.
- Identify top-performing products and categories.
- Understand monthly sales trends.
- Examine order cancellations and returns, if the data is available.
- Provide business recommendations based on the analysis.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Formulas
- Charts and Dashboards
- GitHub

## Analysis Performed
- Sales performance analysis
- Product and category analysis
- Monthly sales trend analysis
- Statistical analysis
- Order cancellation and return analysis, where supported by the data

## Key Insights
- Identify the products generating the highest sales.
- Analyse changes in sales across months.
- Compare sales performance across product categories.
- Identify potential issues with cancellations and returns, if applicable.

## Recommendations
- Maintain sufficient stock for high-performing products.
- Investigate products with low sales.
- Plan inventory according to monthly sales trends.
- Investigate cancellation and return reasons to improve customer satisfaction, where applicable.

## Conclusion
This project demonstrates how Excel can be used to analyse sales data, identify trends, and support data-driven business decisions.
